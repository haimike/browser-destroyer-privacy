DESKTOP DESTROYER / CLASSIC

Privacy Policy

Effective October 1, 2026 · Extension version 2.0.1

The game processes a screenshot of your selected webpage locally. It does not upload that screenshot or send your browsing data to the extension developer.

What the extension does

Desktop Destroyer — Classic is a browser game that draws simulated damage on a frozen image of the visible webpage. This policy covers the extension, including its local launch-help page.

Information processed on your device

When you activate the extension by its toolbar icon or keyboard shortcut, it accesses the current tab's URL and browser tab/window identifiers to check whether the page is supported and target the game. It captures the visible area of that tab as an image and uses that image as the game background. The screenshot may contain any information visible on the page, including personal or sensitive content. It is processed as image pixels; the extension does not extract or analyze text, account details, or messages from it.

During play, mouse or pointer positions, button presses, and relevant keyboard input control the game. Window size, page visibility, and focus are used to manage the overlay and stop held actions. These inputs are not recorded as an activity log.

Purpose and retention

The URL, screenshot, and inputs are used only to start, display, control, and close the game or explain why launch failed. The screenshot and game state are held in browser memory while the scene is active. The extension does not deliberately retain them after exit or page reload and does not write them to files, cookies, Chrome extension storage, or a server. Normal browser memory reclamation is controlled by Chrome.

If launch fails, a local extension help tab displays the launch step and Chrome's error message. Those diagnostics appear in the help tab's local URL and may remain in Chrome's history or restored tabs. Error text can include a page URL or other browser-provided context. Close the help tab and use Chrome's history controls if you want to remove that record. It contains no screenshot.

No developer collection or sharing

The extension sends no screenshots, page URLs, gameplay inputs, or diagnostics to the developer or third parties. It includes no analytics, advertising, account system, remote-code loading, or external-server integration. Graphics and sounds are bundled. User data is not sold, shared, used for advertising, or used to assess creditworthiness or lending eligibility.

Permissions

  • activeTab: grants temporary access after your action so the extension can inspect that tab's URL and capture its visible area.
  • scripting: allows bundled game scripts and assets to create the local overlay in the tab you selected.

The extension does not request ongoing access to every website. Chrome prevents gameplay on protected browser pages.

Your choices

Choose which page to activate the game on. Press Escape, click Exit, or click the extension icon again to close it. Press C to restore the in-memory snapshot or M to mute the sounds. Resizing the browser exits the scene. You can disable or uninstall the extension through Chrome. No developer-held user database exists for this extension.

Limited Use

Desktop Destroyer — Classic's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements. Information is used only for the local, user-requested game and associated launch diagnostics.

Other services and support

Your underlying webpage continues running and may follow its own data practices. Chrome, the Chrome Web Store, and the service hosting this policy also have their own policies. Visiting a help link or voluntarily contacting the publisher is separate from the extension's local game processing. Avoid sending sensitive screenshots or URLs in support requests.

For questions, use the developer contact listed on the extension's Chrome Web Store listing. This policy will be updated if the extension's data practices change.
